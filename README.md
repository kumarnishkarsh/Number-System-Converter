# Number System Converter 

A Python tool to convert numbers between Binary, Octal, Decimal, 
and Hexadecimal — built as a pre-college project.

## Conversions Supported
- Decimal ↔ Binary
- Decimal ↔ Octal  
- Decimal ↔ Hexadecimal
- Any base to any base (2, 8, 10, 16)

## Why I Built This
Number systems are fundamental to Digital Electronics in ECE.
Built this to strengthen the concept before studying it formally.

## Tools Used
- Python

## How To Run
Open in Google Colab and run the cell.
Enter your number, current base, and target base when prompted.
